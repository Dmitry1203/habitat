Сайт с каталогом услуг и портфолио проектов. Проект разработан на Laravel 13 с использованием PHP, MySQL и Blade.

В репозитории опубликованы два примера из публичной части приложения:

- `PublicPortfolioController.php` — страницы направлений, список проектов и галерея.
- `ServiceCatalogController.php` — список разделов услуг и страница раздела с подразделами.

Это выборочные примеры кода, а не полная версия приложения. Административная часть и настройки сервера здесь не опубликованы.
